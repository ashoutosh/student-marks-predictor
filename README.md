# 🎓 Student Marks Predictor

A machine learning web application that predicts student marks based on study hours and attendance.

## 🌐 Live Demo

Try the application here:
https://student-marks-predictor-dju8vbajjxibxt4ei2ubse.streamlit.app/

## 📌 About the Project

The Student Marks Predictor is a beginner-friendly machine learning project built using Python. It uses a trained Linear Regression model to estimate student marks based on the study hours and attendance entered by the user.

## ✨ Features

- Predict marks based on study hours and attendance
- Simple and interactive web interface
- Prediction history during the current session
- Download prediction history as a CSV file
- Visual charts and recommendations

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib
- Machine Learning (Linear Regression)

## ⚙️ Run Locally

1. Clone this repository:

   git clone https://github.com/YOUR_USERNAME/student-marks-predictor.git

2. Open the project folder:

   cd student-marks-predictor

3. Create and activate a virtual environment.

4. Install dependencies:

   pip install -r requirements.txt

5. Run the application:

   streamlit run app.py
